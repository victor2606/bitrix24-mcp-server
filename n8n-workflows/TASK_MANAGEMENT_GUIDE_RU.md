## 📋 Полезные фильтры для задач

### По статусу (поле STATUS)
- `2` = Ждёт выполнения
- `3` = В работе
- `4` = Якобы завершена (ждёт контроля)
- `5` = Завершена
- `6` = Отложена

### По приоритету (поле PRIORITY)
- `0` = Низкий
- `1` = Средний
- `2` = Высокий

### Примеры запросов с фильтрами

```
Покажи все задачи в статусе "В работе" (STATUS=3)
с высоким приоритетом (PRIORITY=2)
```

```

```

```

```

## 🔗 Интеграция с другими системами

### Webhook от Telegram/Slack

Замените **Chat Trigger** на **Webhook Trigger**:

```javascript
// В Code node преобразуйте входящее сообщение
const message = $input.item.json.body.message.text;
const userId = $input.item.json.body.message.from.id;

return {
  prompt: `Пользователь ${userId} написал: "${message}".
           Обработай как запрос по задачам в Bitrix24.`
};
```

### Scheduled задачи

Добавьте **Schedule Trigger** для автоматических отчётов:

```javascript
// Каждый день в 9:00
const prompt = `Создай утренний отчёт:
- Задачи на сегодня
- Просроченные задачи
- Приоритетные задачи недели`;

return { prompt };
```

Затем отправьте результат в **Email** или **Telegram** node.

## ❓ FAQ

**Q: Как узнать ID проекта/пользователя?**
A: Спросите у AI: "Покажи список всех проектов" или "Список пользователей"

**Q: Можно ли создавать повторяющиеся задачи?**
A: Да, через промпт: "Создавай задачу X каждый понедельник"

**Q: Как привязать задачу к сделке/контакту?**
A: Используйте поле `crmEntities`: "Создай задачу и привяжи к сделке D_123"

**Q: AI не находит инструмент?**
A: Проверьте, что в **MCP Client** включены нужные tools или используйте режим "all tools"
